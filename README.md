**INDUSGUARD – Industrial Fault Detection and Safety Alert System**
**Project Overview**
INDUSGUARD is an embedded systems project designed to improve industrial safety by continuously monitoring environmental parameters such as temperature and humidity. The system detects abnormal operating conditions in real time and immediately alerts authorized personnel through SMS notifications, helping prevent equipment damage, production loss, and safety hazards. 
The project is built using the ARM7 LPC2148 microcontroller and integrates multiple peripherals including a DHT11 sensor, EEPROM, LCD, 4×4 Matrix Keypad, GSM Module, and RTC (Real-Time Clock). The system allows both local and remote configuration of operating parameters while maintaining security through password-based authentication. 

**Key Features**

Real-time monitoring of temperature and humidity.
Fault detection based on user-defined threshold values.
SMS alerts sent automatically when abnormal conditions are detected.
Timestamped notifications using the LPC2148 RTC.
Remote configuration through GSM SMS commands.
Local configuration through keypad and LCD interface.
Password-protected access for security.
EEPROM-based storage of passwords, set points, and phone numbers.
Visual fault indication using LEDs/Buzzer.
External interrupt-based settings menu.

System Working
The DHT11 sensor continuously measures temperature and humidity.
Current values are displayed on the LCD.
Stored threshold values are read from EEPROM.
Sensor readings are compared against the configured limits.
If any parameter exceeds its threshold:
Fault indication is activated.
An SMS alert is sent to the authorized mobile number.
The alert includes a timestamp generated by the RTC.
Users can remotely modify set points or request sensor data through predefined SMS commands.
Local users can update set points and passwords using the keypad after successful authentication. 
SMS Command Format
Command	Function
0786T38$	Change temperature set point to 38°C
0786M9866666699$	Update alert mobile number
0786I$	Request current sensor information
All commands require a valid password and authorized phone number for security.
